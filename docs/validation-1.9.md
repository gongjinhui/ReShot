# ReShot 1.9 操作流程调整

2026-11-07，构建 11。Bundle ID、保存目录设置、区域与长截图原快捷键保留。构建摘要见 `evidence/reshot-1.9-build.json`。

## 用户要求与实现

1. 删除附件红框中的“截图与长截图”：正文标题移除，窗口标题仅显示 ReShot 1.9。
2. 将绿框两排入口迁入系统状态栏图标菜单：区域、长图、全屏、窗口、图片导入、粘贴、复制、保存 PNG、截图序列拼接、显示整图、保存目录。图片面板不再重复显示这些按钮。菜单中的“显示整图”带开关状态。
3. 默认隐藏图片面板。区域截图先冻结屏幕，拖选后直接显示标注工具栏，不需要先确认截图再找标注按钮。原有九种标注、颜色/透明度、粗细、撤销/重做均保留。选区支持八方向调整，尺寸标签可拖动整体位置。标注按原图像素处理，调整裁切时更新标注相对坐标。回车或 ✓ 最终确认后才编码、保存 PNG 并复制；Esc 或 × 返回空结果，不产生文件或剪贴板写入。窗口、全屏在图片编辑面板标注后最终确认保存。成功后隐藏编辑界面；保存失败保留图片、预览与复制能力，允许重选目录。
4. 新增窗口截图全局快捷键 Control + Option + W。区域 S、长截图 L 保持原键位。状态栏菜单显示相同修饰键和字符，Carbon 热键按不同 ID 分派。

长截图继续使用 1.8.1 已通过现场测试的滚动、匹配与末屏逻辑，完成后直接保存与复制；仅取消结果改为类型化 CancellationError，取消后不弹出图片面板。OCR 框选仍使用原有确认选择器，识别过程不自动保存无关截图。

本轮依据用户标框截图定位移除/迁移项，依据用户明确要求和此前提供的 iShot 标注栏图示对齐“框选→标注→最终确认”的交互。通过桌面工具观察到本机 iShot 2.6.9 的偏好界面和窗口截图快捷键入口（该机配置为 Option-Z）。ReShot 保持现有 Control+Option 快捷键约定，新增 W，并未修改 iShot 设置。

已有定向反编译证据继续见 `ishot-ghidra.md`；本轮直接修改 ReShot 自有源码，没有复制 iShot 代码、资源或修改其付费机制。未恢复或声称复刻 iShot 未展示的全部交互。
