# ReShot 1.8 验证记录

日期：2026-11-06。macOS Apple Silicon，本机临时签名；Bundle ID 保持 `local.reshot.capture`，构建号 9。最终可执行文件摘要见 `evidence/reshot-1.8-build.json`。

## 功能与证据边界

iShot 的区域截图、长截图、OCR 和自动滚动启动四入口已通过 REA 6.7.0 + Ghidra 12.1.4 实际反编译；入口证据、完整 JSON 和限制见 `ishot-ghidra.md`。没有恢复完整源码，也没有修改 iShot 本体或支付校验。新版本为独立实现。

截图统一了显示器转换、实际像素和元数据，窗口截图采用 macOS 原生高亮选择器且不含阴影；窗口选择器不提供被选窗口的显示器元数据，因此该结果明确为未知，不使用伪造的屏幕 ID 或缩放比例。

长截图增加串行处理、明确状态、持续屏幕流、有界待处理帧、多区域校验、回滚重接、可靠固定头尾检测、自动步长与末尾候选提示。首帧、中间帧及完成时末帧均使用同一屏幕流；静态内容无新完整帧时，在有界等待后重用该流最后的完整样本。没有新的完整样本时，不能保证识别尚未提交给系统合成器的页面变化。

OCR 返回原图坐标及置信度，按几何位置处理分块交界，支持进度、主动取消、迟到结果隔离、编辑、复制、TXT 和合并换行。使用 Apple Vision，本机运行；不保证与 iShot 逐字一致。

## 自动验证

最终源码独立编译到 `.build/ReShot-verify` 后运行七项回归，全部退出 0。随后用同一源码及构建脚本生成 `dist/ReShot.app`；签名完整性验证通过。完整输出见 `evidence/reshot-1.8-tests.log`。

- `--capture-test`：负坐标显示器、纵向坐标转换、Retina 向外像素对齐。
- `--selection-test`：移动限制、边线和角点缩放、最小尺寸。
- `--storage-test`：建目录、唯一文件名、PNG 保存及解码。
- `--stitch-test`：完整逐像素一致、密集帧、重复帧、回滚重接、固定页头/页尾只保留一次、缩略预览尺寸有界、噪声/滚动条、无重叠、周期纹理歧义和尺寸变化。
- `--annotation-test`：原图像素及尺寸、九种标注导出、撤销/重做。
- `--preview-test`：临时文件删除后预览、长图滚动、整图/窗口缩放、PNG/TIFF 粘贴、六帧 5600px 长图显示。测试曾发现窄文字列被多区域校验误拒绝，已修复并通过原样本。
- `--ocr-test`：真实 Vision 中英文、4600px 长图、分块交界、重复段落保留、空白图片、像素坐标、置信度、进度、取消和阅读顺序。

## 桌面验证

通过桌面工具实际观察 ReShot 1.8 主窗口，截图、标注、OCR 控件均可见且布局完整。

- 用户重新授予录屏权限后，全屏截图成功回到预览，提示自动保存并复制，PNG 已落盘。
- 区域截图由用户完成选择并确认，成功显示、自动保存、复制。工具不能拖动覆盖层，因此不将这次人工框选描述为自动操作。
- Safari 本地验证页 `evidence/fixtures/plain.html` 已打开。用户框选并滚动后，面板显示已拼接 31 帧、1333 × 3574px，长图缩略图可见。
- 现场首次完成操作出现“最后一屏未接上，未保存”，确认不完整结果没有误保存；取消后恢复主窗口，可再操作。随后统一首尾屏幕流并修复匹配回归。最终构建现场复测成功：用户确认完整长图及已保存提示；工具核对到落盘的 1377 × 2273px PNG（文件见 `evidence/reshot-1.8-desktop.json`），并观察复制提示。
- 临时签名重建确实导致旧录屏授权记录不匹配。系统开关显示开，并不等同当前构建已通过 `CGPreflightScreenCaptureAccess`；关闭再开启并重启后，真实截图已成功。

最终长图的 OCR 窗口实际识别出连续第 023–031 条中英文内容，按序出现且未见分块重复。桌面工具在 TXT 保存对话框中无法输入路径，随后重新连接出现 SCStream -3811 工具错误，未将界面 TXT 导出记为通过。

尚待实际确认：自动滚动至末尾、固定页头网页现场效果、原生滚动列表、窗口截图选择完成、真实多显示器。合成样本和构建通过不替代这些桌面验收。

## 运行限制

最大输出 60000px 高 / 192MB 原始 RGBA；应用运行时还保留当前视口和预览，因此实际总内存大于输出缓冲限制。无重叠跳页、动画、纯空白及周期重复内容可能暂停并要求调整选区。固定栏只在纹理稳定且剩余内容唯一对齐时自动排除。自动滚动只向所选应用发送输入，目标窗口遮挡、鼠标移出、焦点变化或权限不足会暂停。

最低 macOS 13 保留截图兼容路径；本机没有真实运行旧系统或不同硬件，不声称这些已端到端验证。官方教学视频本轮未重新完整观看，行为参考以现有历史记录及可核验的静态证据为限。
