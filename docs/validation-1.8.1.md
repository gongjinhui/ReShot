# ReShot 1.8.1 自动滚动修复

2026-11-06；构建号 10。Bundle ID 和保存设置保持不变。可执行文件摘要见 `evidence/reshot-1.8.1-build.json`。

## 已观察问题与修复

用户现场反馈 1.8 自动模式没有滚动。工具观察主窗口已有保存提示，但没有保留当时控制面板状态，因此不能确认原故障究竟是权限、窗口校验还是目标未响应投递；不将下述可疑路径描述为已证实的唯一根因。

原代码直接 postToPid，改为经系统 HID 事件流路由滚轮，发送前仍严格检查鼠标位于选区、目标应用前台、鼠标下是原窗口、辅助功能及事件投递权限有效。事件使用像素单位、向下的垂直轴、正确的 CG 屏幕位置，清除 Shift 等修饰键；不发送鼠标点击。这里保证的是投递前校验，系统事件发送与窗口变化之间仍可能存在竞争。

辅助功能或事件投递权限不足时不再静默切回手动模式：保持自动模式并显示明确的“未启动”提示。用户重新授权后可点击继续；也可主动选择手动模式。目标关闭、失去焦点、被遮挡分别提示，权限提示不会再被第一帧进度覆盖。

连续三次无变化时，仅已有滚动进度才提示疑似末尾；从未采到新内容则明确提示没有检测到滚动。自动模式未捕获滚动内容时，完成操作需要明确选择继续采集、只保存当前一屏或取消，避免单屏被静默当成长图。

- 原有截图坐标、选区、保存、拼接、标注、预览及真实 Vision OCR 七组测试全部通过。

本机临时签名重建可能使旧的录屏／辅助功能授权失效。须完全退出旧进程，打开当前 `dist/ReShot.app`，按系统要求重新允许当前构建。判断是否可自动滚动以应用实际提示为准，不能只看系统开关外观。

实现参考：[Apple CGEvent](https://developer.apple.com/documentation/coregraphics/cgevent) 及 [像素滚轮标志](https://developer.apple.com/documentation/coregraphics/cgeventfield/scrollwheeleventiscontinuous)。
