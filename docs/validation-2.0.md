# ReShot 2.0 框选、录屏和序列拼接

2026-11-07，构建 14。应用 `dist/ReShot.app`，Bundle ID 与默认保存目录设置沿用原版。摘要见 `evidence/reshot-2.0-build.json`。

- 删除附件所示的顶栏文字。在当前显示器的鼠标位置立即初始化像素十字线和像素坐标，跟踪移动；第一次按下可开始拖选。按下、拖动、松开后直接显示标注栏，拖选期间不弹出标注控件抢占手势。
- 取色、粗细调节入口和其他图标的外框统一为 26×24pt，标注栏宽 473pt、高 32pt。粗细滑杆由同尺寸按钮打开，颜色/透明度、撤销、取消和确认仍可用。
- 状态栏“录屏…”框选后开始，支持暂停、继续、结束并保存。使用 ScreenCaptureKit 采集当前选区，排除本应用窗口，使用 AVFoundation 编码 H.264 MP4。录制画面及光标，无音频轨。暂停时不写帧，单调时间轴不计暂停时长；不变化的画面也保持实际录制时长。输出在 PNG 的同一保存目录，以完成文件取代同目录临时文件；结束后可从状态栏定位最近视频。退出时先完成正在写入的视频。显示器或屏幕流中断会尝试保留已录片段并报告中断。
- 导入序列使用独立的纵向排版流程：文件名自然排序，可上移/下移；任意内容、重复项、不同宽高均可按顺序拼接，原尺寸保留、窄图居中透明补边。输出保留 60000px 高和 192MiB 像素缓冲上限。自动/手动滚动长截图继续用重叠匹配。

参考本机观察到的 iShot 十字线选项、[iShot 录屏说明](https://www.better365.cn/ishot/screenrecording.html)和 [Apple ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit?changes=_5__8)。本轮用自有实现覆盖请求的操作，没有复制 iShot 代码或资源。

## 2.0.1 录屏边框与标注

用户验收反馈要求录制时显示边框、实时标注工具栏以及暂停、继续和停止按钮。构建 15 已加入这些操作。标注工具包含画笔、线条、图形、文字、序号、高亮、撤销、重做和清空。选择“操作桌面”后可以操作选区内的应用。截图标注中的马赛克使用静态图片源，录屏工具栏采用可直接叠加到视频的标注工具。

真实屏幕采集排除应用窗口，编码器把独立的透明标注层合成到每个录制帧。暂停时边框为橙色且时长停止累计。现有 workflow 测试检查边框、绘制模式、鼠标穿透和清空后的编码状态。recording 测试编码并解码 60 帧，在合成画面中核对标注在 Retina 比例下的位置、方向及背景像素，成片时长约 2 秒。五组针对性回归通过，见 `evidence/reshot-2.0.1-tests.json`。本构建的实机绘制、暂停与停止操作待用户复测。

2.0.1 后续实机验证已完成录屏启动、暂停和结束保存。控制面板实际显示标注工具、“录屏中”和停止按钮，点击暂停后显示“已暂停”和“继续”，随后再次观察到运行状态。新增 MP4 在图片目录保存，完整解码通过，1580×476，共 1862 帧，约 62.06 秒。第一帧无红色标注，末帧可见红色矩形、直线与画笔笔迹，证明实时标注进入成片。相关像素计数在同一规则下由 0 增为 27438。当前仅剩首次拖选及初始像素线、去除顶部提示的现场反馈。


## 2.0.2 录屏确认位置与内容跟随

用户要求录屏确认、取消显示在选区正中下方，且标注随内容滚动，目标消失后一起消失。构建 16 已加入这些行为。

区域选择器将两按钮整体居中放在选区下方，靠屏幕边缘时避让。录屏标注按每个标记的图像局部特征匹配目标位置，跟踪输入使用应用界面已排除的屏幕帧。视频合成和桌面标注同步采用追踪坐标。标记离开视口、目标被替换或可靠匹配丢失时清除。撤销和重做历史随坐标更新，清除的目标从历史记录移除，防止恢复到旧位置。绘制过程中暂停位置追踪，完成笔画后建立目标特征。低纹理、重复内容或遮挡可能导致提前清除，需要实机检查。

七组回归通过，见 `evidence/reshot-2.0.2-tests.json`。新增跟踪测试覆盖向上滚动、奇数像素回滚、目标替换、滚出视口，以及坐标同步的撤销重做。工作流测试检查录屏确认/取消整体居中且位于选区下方。录屏编码、原有截图标注、预览、任意序列拼接、选区边界等回归通过。应用签名检查通过。

桌面工具连接当前应用超时，已请求用户在当前版本标注段落后滚动，核对屏幕和 MP4 中的跟随及消失行为。当前尚待该项现场反馈。


## 2.1 边框、音频与图标控制

用户要求蓝色细虚线和四角、录屏声音、图标控制，随后确认音源为系统声音和麦克风。构建 17 使用这两路音源。屏幕边界由 0.5pt 蓝色虚线和 1.5pt 四角线组成。控制面板的暂停/继续、停止保存、取消录制使用图标与辅助功能名称。回车触发停止保存。取消会终止采集并清除本次临时文件。

系统声音由 ScreenCaptureKit 输出，麦克风由 AVCaptureSession 输出，两者先换算到主机时钟，再映射到同一个排除暂停时段的媒体时间轴。麦克风音频转换为 48kHz 双声道后与系统声音混合，输出单条 AAC 音轨。麦克风会在使用前请求系统权限，权限被拒绝时给出具体提示。启动和停止麦克风使用独立队列。

最终构建七组回归通过，见 `evidence/reshot-2.1-tests.json`。音频测试将 48kHz 双声道系统测试音与 44.1kHz 单声道麦克风测试音输入生产混音流程，编码 MP4 后读回唯一音轨，验证 440Hz 与 880Hz 两路成分、约 2 秒成片时长，以及取消后的临时文件清理。录屏画面、暂停、标注位置、目标跟随、截图和序列拼接回归通过。签名检查通过。

桌面工具报告 Mac 已锁定，真实麦克风、系统播放声音和图标操作仍待解锁后的现场测试。

接口依据 [Apple ScreenCaptureKit 音频配置](https://developer.apple.com/documentation/screencapturekit/scstreamconfiguration)及 [AVCaptureSession 同步时钟](https://developer.apple.com/documentation/AVFoundation/AVCaptureSession/synchronizationClock)。

2.1 用户对双路录音、蓝色边框、暂停继续、停止保存和取消丢弃回复“正常”。图片保存目录中新 MP4 的 H.264 视频约 46.070 秒，48kHz 双声道 AAC 约 46.055 秒，源包解码时间戳严格递增，文件可完整解码。实际音源和控件效果以用户复测为准。区域首次拖选仍未能通过桌面工具观察，录屏标注随可见对象移动的现场行为仍待确认。

最终验收中，用户回复“都正常”，确认进入区域截图时显示像素十字线、没有顶部提示，第一次拖动即可完成框选。录屏标注随可见段落移动，段落滚出后标注消失。结合此前双路录音、控制图标和边框的现场确认、统一尺寸控件的工作流测试及序列成图像素核对，本轮目标验收通过。
