# ReShot 2.1

独立实现的 macOS 截图、纵向长截图和本机中英文 OCR，保留图片标注。构建产物为 `dist/ReShot.app`，最低 macOS 13；macOS 14+ 使用 ScreenCaptureKit 过滤自身窗口和持续采集。

运行 `bash scripts/build.sh` 构建并打开 `dist/ReShot.app` 后，从 macOS 菜单栏进入各项功能。首次使用截图或录屏时按系统提示授权。完整操作步骤见[简明使用说明](docs/reshot-build-story.md#reshot-21-简明使用说明)。

## 默认快捷键

- **⌥A** 区域截图，**⌃⌥W** 窗口截图，**⌃⌥F** 全屏截图，**⌃⌥L** 长截图。
- **⌥O** 框选识字，**⌃⌥O** 识别当前图片。
- **⌥S** 从剪贴板载入图片，**⌥W** 开始或停止录屏。
- **⌘,** 打开偏好设置。前八个功能快捷键可在偏好设置中修改。

## 截图

- 启动时只显示系统状态栏图标，图片面板默认隐藏。截图、导入、识字、录屏和偏好设置入口均在图标菜单里；需要时选择“显示图片面板”。按 Option + S 可从剪贴板载入图片。
- 区域截图：Option + A。冻结当前屏幕画面，进入即显示十字像素标线，无顶部提示；松开鼠标完成框选后恢复系统箭头，并显示悬浮标注工具栏；选择工具下可拖动尺寸标签移动选区、拖动边线或角点调整大小；切换到标注工具后选区固定，避免落笔或松开鼠标误改选区。标注位置跟随明确的裁切调整更新。最终按回车或点 ✓ 才保存并复制；Esc 或 × 放弃。
- 窗口截图：Control + Option + W。使用 macOS 原生窗口高亮选择器，点击后进入标注面板，最终确认才保存；Esc 取消，默认不含窗口阴影。
- 全屏截图：Control + Option + F，截取鼠标所在的显示器。区域限定在单个显示器内，支持 Retina 与负坐标外接屏。
- 区域截图确认后隐藏工具栏，窗口／全屏截图在标注面板确认后隐藏面板，按偏好格式保存并复制到剪贴板。自动保存失败时仍可复制和预览，可在偏好设置重选目录后返回图片面板确认保存。取消不写文件或更改剪贴板。

## 偏好设置

在状态栏选择「偏好设置…」。

- 点按功能旁的快捷键按钮，再输入字母或数字与 Control、Option 或 Command 的组合，可同时按 Shift。按 Esc 取消。更改即时生效，冲突时保留原键。
- 图片和视频可分别设置保存目录，默认均为 `~/Pictures/ReShot`。从旧版升级时，两个目录起初沿用原保存目录。
- 图片默认保存为 PNG，也可选择 JPEG 或 TIFF。JPEG 的透明区域以白底保存，视频保存为 MP4。
- 勾选「显示整图」可将图片缩放到面板内，选择会在下次启动时保留。
- 勾选「登录时打开 ReShot」可随 macOS 登录启动。如需系统批准，前往「系统设置 → 通用 → 登录项」。

## 圆角与标注栏

悬浮标注栏按控件内容收紧至 473×32pt，取色、粗细及图标按钮均为 26×24pt；点击粗细图标再调节滑杆，保留全部标注工具及撤销、重做、取消和确认。

在状态栏打开“偏好设置…”可设置区域截图和合成长图的圆角半径，默认 10pt，支持 0–100pt，0 为直角；设置会持久保存。区域选框和预览显示相同圆角，PNG、TIFF 和剪贴板图片的圆角区域保留透明。圆角设置不会改变图片尺寸。屏幕采集按所选显示器的像素比例换算（例如 Retina 10pt = 20px）；导入序列和 CLI 拼接不含显示器缩放信息，按 1pt = 1px 处理。长截图仅在最终合成后处理四角，不对各帧分别裁圆，以免在接缝留下缺口。

## 长截图

Control + Option + L，选择并确认同一显示器内的滚动内容区域。

- 默认手动模式：在选区内滚动时采集，静止时不追加；可暂停、继续、完成或取消。
- 自动模式：在控制面板选择“自动滚动”，允许辅助功能权限后，把鼠标移入选区。程序恢复所选应用的焦点，根据匹配进度调整滚动步长。事件经过系统窗口路由；每次发送前检查原目标应用、鼠标下方窗口、焦点和输入权限。权限不足时停留在自动模式并明确暂停，可重新授权后继续或手动切换模式。鼠标移出、窗口遮挡或失去焦点会暂停；点击继续恢复。
- 连续三次滚动后无新内容时暂停；此前已有滚动进度才提示“疑似到达末尾”，完全没有进度则提示目标没有响应或可能已在末尾。未采到滚动内容时，完成操作会要求继续采集、仅保存当前画面或取消，不将一屏静默当作长图。
- 预览随内容增长，重复帧不追加；回滚后接上已有内容不会重复保存。固定页头/页尾只在可靠检测且匹配成功时保留一次；无法确认时需缩小选区避开固定栏和动画。
- 无重叠跳页、模糊或歧义匹配会明确暂停。请回滚少许重接，再继续下滚；末屏没接上不当作完整长图保存。
- 输出上限为 60000px 高 / 192MB 原始 RGBA，达到上限后可明确完成当前内容。输出内存限制不等于整个应用的总内存用量。
- 点击「完成截图」后，ReShot 检查最后一个视口，按偏好格式保存长图，并将 PNG 副本放入剪贴板。点击「取消」放弃本次结果。

## 录屏与序列拼接

- 状态栏“开始/停止录屏”（Option + W）：在单个显示器内框选，点“开始录屏”或回车。选区边框为蓝色细虚线，四角加重显示。控制面板提供标注工具以及暂停/继续、停止保存、取消录制三个图标。再次按 Option + W、按回车或点停止图标可保存，取消图标会丢弃本次视频。标注写入视频，点“操作桌面”可切回普通鼠标操作。标注通过画面匹配跟随目标，滚出视口或目标匹配失效时清除。录屏确认和取消按钮显示在选区下方中央，屏幕边缘自动避让。结束后在视频保存目录生成 H.264 MP4；可在状态栏菜单打开最近录屏位置。视频包含画面、光标、系统声音与麦克风，首次使用需要允许麦克风权限。两路声音混合为一条 AAC 音轨，暂停时间从音画时间轴中同时去除。
- “导入图片拼图”：选择两张或更多图片，初始按文件名自然排序，可上移/下移。拼接按列表从上到下保留原尺寸和重复图，窄图居中、两侧透明，不需要内容重叠；确认后保存。此功能独立于滚动长截图的重叠匹配。
- 命令行 `--join OUTPUT IMAGE1 IMAGE2 ...` 按参数顺序直接拼接；`--stitch` 仍用于有重叠的滚动截图序列。

## OCR 与标注

“识别当前图片”（Control + Option + O）识别当前图片，“框选识字”（Option + O）先选择屏幕区域；导入、粘贴图片或长图也可识别。默认简体、繁体和英文，全部在本机使用 Apple Vision，不上传图片。支持进度、取消、可编辑结果、复制、UTF-8 TXT 导出和合并换行。长图按原始像素重叠分块，通过坐标处理边界重复；不同位置的相同段落保留。

已有矩形、圆、直线、箭头、画笔、马赛克、文字、序号和高亮继续可用，支持颜色、粗细、移动、删除及撤销/重做；复制和保存包含标注，重新导入 PNG 不恢复矢量标记。

需要 Apple Command Line Tools。构建脚本会生成本机架构的应用、打包图标并进行临时签名。重建可能使 macOS 旧权限失效：退出 ReShot，在系统设置中关闭再开启其屏幕录制开关，再打开；仍被拒绝时移除旧项，重新添加当前 `dist/ReShot.app`。辅助功能仅自动滚动需要，拒绝后仍可手动截图。
